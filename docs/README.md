# Hostel Finder Documentation

Welcome to the official documentation for **Hostel Finder**.

Hostel Finder is a web-based platform designed to help students and other users discover, search, and manage hostel accommodation information through a simple and user-friendly interface.

The project is built with:

- React + TypeScript
- Node.js + Express.js
- PostgreSQL
- Docker
- Docker Compose
- Nginx
- GitHub Actions
- GitHub Container Registry (GHCR)
- AWS EC2
